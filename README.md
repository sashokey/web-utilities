Standalone browser utilities in one sidebar. The collection includes a password generator for word-based and random-character passwords. It requires a browser with JavaScript and Web Crypto.

## Installation

Open [the collection](https://sashokey.github.io/web-utilities/). For offline use, save [the standalone password generator](https://sashokey.github.io/web-utilities/password-generator/index.html) as an HTML file and open it in your browser.

## Usage notes

Copy the collection URL after selecting a utility to share that selection. Passwords are generated on the device. If clipboard access is unavailable, select the displayed password and copy it manually.
